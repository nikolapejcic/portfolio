# Portfolio

Two versions of the portfolio site, served locally with live reload.

- `v1-cards/`: card layout
- `v2-figma/`: Figma-based layout
- `index.html`: a page with links to both versions

## Start the server

Open Terminal and run:

```bash
cd ~/Projects/portfolio && npm run dev
```

Your browser opens at http://localhost:3000. Any change you save to an HTML or CSS file shows up in the browser right away.

- v1: http://localhost:3000/v1-cards/
- v2: http://localhost:3000/v2-figma/

## Stop the server

Click into the Terminal window where the server is running and press **Ctrl+C**.

## First time on a new computer

Install Node.js (LTS) from https://nodejs.org, then run this once inside the folder:

```bash
npm install
```
